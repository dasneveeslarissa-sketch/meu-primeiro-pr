# Meu Primeiro PR

Repositório criado para aprender a abrir Pull Requests no GitHub.

## O que é um Pull Request?

Um Pull Request (PR) é uma forma de propor mudanças em um repositório. Você cria uma branch, faz alterações, e abre um PR para que as mudanças sejam revisadas antes de entrar na branch principal.

## Como contribuir

1. Crie uma branch nova
2. Faça suas alterações
3. Abra um Pull Request
